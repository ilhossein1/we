## University of Ottawa — Mechanical Engineering (thesis master's)

Checked 2026-10-07. Main sources: uOttawa graduate catalogue page for the program, Faculty of Engineering program page, uOttawa "How to apply" (graduate) page, and the Faculty of Engineering thesis-supervisor and scholarship pages.
Note: uOttawa keeps program deadlines, test scores and documents in an interactive "Check requirements" tool (https://www.uottawa.ca/study/graduate-studies/program-specific-requirements, which embeds https://dnn.uottawa.ca/en/Utilities/Specific-Requirements/Graduate-programs). The tool only works by submitting an ASP.NET form (postback), so I did not use it (no form-filling rule). The deadline, number of references and any program-specific test scores are probably shown there, so a person needs to check it in a browser.
